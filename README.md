# ☕ cozy study timer v2

An aesthetic Pomodoro study timer with 4 themes, lofi music, rain effect & task tracking.

## features

- 🎨 **4 Themes** — Cozy, Girly Purple, Night Owl, Spring (switch instantly!)
- 🍅 **Pomodoro Timer** — 25/5/15 min focus & break sessions with SVG ring
- ✍️ **Task List** — add, complete & clear tasks (saved in localStorage)
- 🌸 **Mood Tracker** — log how you're feeling before you study
- 🎵 **5 Music Streams** — lofi, jazz café, study piano, nature, chillhop
- 🌧 **Rain Effect** — animated canvas raindrops toggle
- 📊 **Daily Stats** — sessions, minutes, tasks & streak tracker
- 💾 **Persistent Storage** — tasks & streak saved across sessions

## project structure

```
study-timer/
├── index.html   ← structure
├── style.css    ← all styling + 4 themes
├── script.js    ← all logic
└── README.md    ← this file
```

## tech stack

- HTML5 + CSS3 (CSS variables, animations, grid/flexbox)
- Vanilla JavaScript (no frameworks!)
- Canvas API (rain animation)
- localStorage API (data persistence)

## how to run

```bash
git clone https://github.com/Bargavisivaraman/study-timer
cd study-timer
open index.html
```
